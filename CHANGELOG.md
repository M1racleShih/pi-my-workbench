# Changelog

## 0.1.1 - 2026-11-06

- Show the workbench once in the collapsed startup summary, while Ctrl+O retains all six native resource paths and diagnostics.
- Use Block Editor's optional generic grouping API through a one-module adapter; keep independent factories, filtering and load identities.
- Add local/Git summary integration tests and an isolated regular/fullscreen TUI smoke script.

## 0.1.0 - 2026-11-06

- Aggregate four independently maintained Pi extensions with exact upstream pins and separate resource entry points.
- Adopt the standalone `/clear` session command without changing its session-replacement behavior.
- Add an opt-in model-overrides loader; no personal model list or credentials ship with the workbench.
- Provide reversible local development links, native Pi loader tests and package-safety checks.

This version is distributed through GitHub. npm publishing is intentionally disabled.
